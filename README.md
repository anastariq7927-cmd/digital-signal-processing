# Digital Signal Processing

A practical introduction to **Digital Signal Processing (DSP)** using Python. This project explores fundamental signal processing techniques through numerical implementations, audio experiments, and signal analysis.

## Topics Covered

- **Signal Generation:** Sampling and generation of sinusoidal signals.
- **Signal Quantization:** Quantization, quantization noise, and Signal-to-Noise Ratio (SNR).
- **Audio Processing:** Audio recording, playback, segmentation, and resampling.
- **Signal Classification:** Autocorrelation and identification of voiced and unvoiced signals.
- **Frequency Analysis:** Discrete Fourier Transform (DFT), FFT, spectral analysis, and zero-padding.
- **Sampling Rate Conversion:** Upsampling, downsampling, and aliasing.

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- SoundFile

## Purpose

The goal of this project is to understand and implement core DSP concepts, combining theoretical foundations with practical experiments and numerical analysis.
